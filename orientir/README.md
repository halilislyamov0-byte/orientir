# Ориентир — персональный маршрут поступления

Проект для LOCUS Startup Hackathon 2026, Кейс 02. Промокод сабмита: `LOCUSCASE2`.

## Задача

Абитуриенту 9–11 класса, рассматривающему поступление в разные страны, нужен не
список университетов, а понятный маршрут: диагностика профиля → подходящие
программы с объяснением → сравнение → пошаговый план → один ближайший шаг.

## Решение

Полностью AI-first подход (Вариант C): фиксированной базы вузов нет —
Gemini на основе анкеты генерирует диагностику, минимум 3 рекомендации,
таблицу сравнения, roadmap и ближайший шаг **одним запросом**, возвращая
строгий JSON. Любые цифры, в которых модель не уверена (стоимость, дедлайны),
помечаются флагом `isDemoData` и явно подсвечиваются в интерфейсе — это
закрывает требование кейса о честной маркировке демонстрационных данных.

Прогресс анкеты, результат и отмеченные шаги roadmap сохраняются в
`localStorage`, поэтому весь путь работает без бэкенда и логина — согласно
кейсу это допустимая замена сложному backend.

## Стек

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS v4 (дизайн-токены через `@theme` в `app/globals.css`)
- Gemini API (`gemini-2.0-flash`, `responseMimeType: application/json`)
- Без БД в MVP — состояние в `localStorage` (см. «Дальнейшее развитие»)

## Архитектура

```
app/
  page.tsx              — Этап 1: вход, объяснение ценности
  journey/page.tsx       — Этапы 2–7: анкета → диагностика → рекомендации →
                            сравнение → маршрут → следующий шаг (один client-компонент
                            с навигацией по этапам слева)
  api/generate/route.ts  — серверный роут, вызывает Gemini и возвращает JSON
lib/
  types.ts    — типы профиля и результата маршрута
  prompt.ts   — промпт со строгой JSON-схемой
  gemini.ts   — клиент Gemini API
  storage.ts  — сохранение профиля/результата/прогресса в localStorage
```

## Запуск

```bash
npm install
cp .env.example .env.local   # вписать GEMINI_API_KEY
npm run dev
```

Открыть http://localhost:3000

## Тестовый сценарий (как проверяет жюри)

1. На главной — «Построить мой маршрут» → заполнить анкету (класс, интересы,
   предметы, языки, экзамены, страны, бюджет, сроки).
2. Пройти диагностику → рекомендации → сравнение → маршрут → следующий шаг.
3. Вернуться к анкете, изменить бюджет или страну, пересчитать — маршрут и
   рекомендации заметно меняются.
4. Отметить шаги в roadmap — прогресс-бар на последнем экране обновляется.
5. Проверить мобильную версию (интерфейс адаптивный).

## AI и данные

- Модель: Google Gemini (`gemini-2.0-flash`) через `generateContent`.
- Данные об университетах не хранятся в БД — генерируются моделью под профиль.
  Модель проинструктирована помечать неточные/оценочные цифры как демо-данные
  вместо выдачи их как проверенных фактов.
- Демо-баннер с дисклеймером выводится на финальном экране.

## Ограничения MVP

- Нет реальной базы вузов — точность зависит от модели; для дальнейшего
  развития стоит добавить курируемый датасет (Вариант D) поверх текущей логики.
- Нет аутентификации — состояние привязано к браузеру пользователя
  (localStorage), не синхронизируется между устройствами.
